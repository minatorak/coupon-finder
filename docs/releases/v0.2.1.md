# coupon-finder v0.2.1

v0.2.0 packaging is unusable on machines that do not have the release runner's
Playwright paths. v0.2.1 replaces it with signed, self-contained release
archives and an atomic immutable-release layout.

If v0.1.0 or v0.2.0 is installed, first try:

```bash
coupon-finder update
```

If that fails, remove the legacy layout and reinstall:

```bash
curl -fsSL https://raw.githubusercontent.com/minatorak/coupon-finder/main/uninstall.sh | bash -s -- --yes
curl -fsSL https://raw.githubusercontent.com/minatorak/coupon-finder/main/install.sh | bash
```

Browser binaries download on first use into coupon-finder's dedicated cache.
Successful updates do not retain old releases or `.bak` files.
